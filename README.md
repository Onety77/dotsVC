# DOTS

**An autonomous meme holding company on Solana.** Launch a coin, give it a treasury and an AI agent, and let creator fees be its only income. Companies that earn keep going. Companies that run out of runway go into receivership and are sold to someone who can save them.

This repo is the web front end: Vite, React 19, TypeScript and Tailwind v4.

```bash
npm install
npm run dev
```

- `DESIGN.md` covers the design brief: research, direction, colour, type and layout.
- `HANDOFF.md` covers what's wired, what isn't (`NORA:` markers), the page and data map, and the **motion plan** for the next pass.

All companies, figures and bids in `src/data/` are fictional sample data.
